# CHEATSHEET.md — cumulative command reference

> **Stub.** This file is assembled in Phase 4 from every lesson's command list, in syllabus order.
> It is deliberately empty until then: a cheatsheet written before the lessons would leak commands
> ahead of the lesson that teaches them, breaking the dependency rule.

Once built, it will hold, per chapter, every command and flag the course has formally introduced up
to that point — and nothing beyond it. Use it as a lookup for things you've already learned, never
as a way to skip ahead.

Commands you find in `man` during Dig-tier exercises are yours to keep, but they won't appear here
unless a later lesson teaches them properly.
